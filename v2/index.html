03 / case study

behind the code

한 프로젝트를 깊게 풀어 봅니다 — 문제, 가설, 접근, 결과, 회고.

Featured · 01

3개국어 단일 마크업 — 글로벌 테크 사이트

2023.09 — 2023.12 · 메인 퍼블리셔 · 디지털 크리에이티브

01

Problem

언어별 템플릿이 분기되어 SEO 누수와 유지보수 비용이 컸다. 일문은 영문 대비 평균 1.4배 길어 박스 깨짐이 빈번했다.

02

Hypothesis

CSS Grid의 minmax()와 clamp() 기반 fluid 타이포그래피로 텍스트 길이 변동을 흡수할 수 있다.

03

Approach

마크업 한 벌 + 토큰 분리. Figma Variables ↔ SCSS map 1:1 매칭. 폰트 5종 → 2종, critical CSS 인라인.

04

Result

LCP 2.1s → 0.8s (62% ↓). Lighthouse a11y 78 → 96. QA 리젝 0건. 후속 페이지 onboarding 3일 → 1일.

05

Reflection

다시 한다면 토큰 시스템을 첫 주에 디자이너와 함께 정리하겠다. 토큰이 늦게 들어오면 마크업이 두 번 작성되는 비용이 크다. 이후 NVDA 검증을 내부 QA에 정식 단계로 추가했다.
