# 완료 전 체크리스트 — publishing 스킬 §13 의 본문

> **언제 여는가** — 페이지·컴포넌트 작업을 "끝났다"고 보고하기 전에 연다. 아래를 전부 확인한다. 다른 스킬의 체크리스트는 여기로 모았고, 그쪽에는 해당 스킬에만 있는 항목만 남겼다 (`figma-to-html` §4 = 피그마 대조·실측, `a11y-check` = 접근성 실측 절차).
> 괄호 안의 `§N` 은 `SKILL.md` 의 절이다.

### 마크업

- [ ] `html/_template.html` 에서 시작했다 — 스킵 링크, `<main id="content">`, `<h1>` 1개, heading 위계, 숨김 제목(`<h_ class="blind">`) 없음 (메인처럼 대표 타이틀이 안 보이면 `<h1>` 없음), `<title>`·keywords·description·OG (§9 — SEO 설정표가 있으면 `PROJECT.md` 「SEO 태그」 값)
- [ ] 같은 디자인은 가이드/기존 페이지와 **같은 태그·같은 클래스** (§6)
- [ ] 개발이 바꿀 상태(탭 · 페이지 번호 · 비활성 · 오류) 위에 `<!-- @ -->` 주석 — 가이드 것을 그대로 (§12)
- [ ] 개발이 채울 값(탭 `value` · `option` 코드값) 없음 — `value=""` 만 (§12)
- [ ] 주석에 화면 ID · 피그마 노드 · 날짜 · 참고 사이트 · 내부 문서 참조 없음 — HTML · CSS · JS 모두 (§2)
- [ ] 반복 샘플 2~3건 (반복 주석 없음), 항목 수·텍스트 길이·이미지 유무에 깨지지 않는다 (「설계 원칙」)
- [ ] 마크업에 `.font-*` 클래스 없음 (에디터 본문 예외) — 글자는 선택자의 변수 (§10)
- [ ] 고정 틀(썸네일 · 배너) 안 `<img>` 에 `width` · `height` 없음 — 원본 비율대로 늘어나는 본문 · 상세 예시 이미지에만 (`markup.md`)
- [ ] 시맨틱 태그, `<table>` `<caption>` + `<th scope>`, 빈 링크 `href="javascript:"` (§3)
- [ ] 인라인 `style`·`<style>`·인라인 SVG 아이콘 없음 (§1 — 표 열 폭 `<col style="width">` 만 예외)

### 네이밍·CSS

- [ ] 케밥, 루트 3단어 이하 · 자식은 역할 이름 1~2단어(루트 접두어 반복 없음, `tit` · `txt` 축약), BEM `__`/`--` 없음, 이름에 값(`.h64`·`.mt20`·`.blue`) 없음, 상태는 `is-` 목록 안에서만, 진입 모션 대상은 `data-motion` 속성 (§6)
- [ ] 변형은 변형 클래스로, 페이지 스코프에서 공통 컴포넌트 덮어쓰기 없음 (§6)
- [ ] 모양만 다른 반복 목록은 마크업 한 벌 + 부모 모양 클래스(형태 이름) — 부모 클래스만 바꿔 다른 모양이 되는지 확인 (`naming-components.md` 「모양 클래스」)
- [ ] 구조 선택자(`>` · `+` · `~` · `:first-child` · `:last-child` · `:nth-child`)는 클래스 + 자손 선택자 · `gap` · `:has()` 로 안 되는 곳에만, 형제 결합자는 `+` 없이 `~` 로 (§6)
- [ ] 색·글자가 토큰, `:root` 는 `_tokens.scss` 에만, HEX 하드코딩 없음, 간격은 스케일 안 (§7)
- [ ] 선택자의 글자는 `font` + `letter-spacing` 두 줄뿐 (굵기만 다른 변형의 `font-weight` 한 줄 예외), 미디어쿼리의 글자는 다른 스타일로 바꾸는 두 줄뿐, `font-size: 0` 숨김 없음 (§10)
- [ ] 단위 — rem, 보더·그림자·브레이크포인트·터치 타깃만 px (§7)
- [ ] `z-index` 는 `--z-*` 토큰만 (§7)
- [ ] 체크 · 라디오는 박스 + 표시를 합친 상태별 피그마 SVG 를 `input` 배경으로 — CSS 테두리 · 도형 · `mask` 없음 (`assets.md` 「폼 표시」)
- [ ] 컴포넌트 루트에 바깥 margin 없음, 여백은 컨테이너가 (§4 · §6)
- [ ] 브레이크포인트 1024 / 600 만, 1920·1024·600 에서 가로 오버플로 없음 (§5)
- [ ] `:hover` 에 `:focus-visible` 동반 + `@media (hover: hover)` 로 감쌈(기본 상태는 밖), `outline: none` 금지 — 링은 전역 `:focus-visible` (포커스 테두리가 있는 입력 부품만 예외). 포커스 가능한 요소에 직접 `mask` 없음, `transition: all` 대신 속성 명시 (`css-rules.md` 「디자인 데이터에 없는 속성」)
- [ ] 골격은 `scss/common/`, 부품은 `scss/components/_부품.scss`(첫 등장부터), 한 페이지 디자인은 `scss/components/_style.scss` 의 그 페이지 구획(페이지마다 파일을 만들지 않는다) · 섹션에 이름 클래스 없음(`<section class="sec">`) (§1)
- [ ] `scss/` 만 고쳤고 `npm run scss` 로 `css/` + `.map` 을 갱신했다. 마크업 경로대로 끝까지 중첩했다(루트 반복 · 단계 건너뛰기 · `.a .b {` 처럼 한 줄에 이어 쓴 선택자 없음 — 상태 · 덮어쓰기 · 반응형도 같은 경로), `&-접미` · `@extend` 없음, 출력 CSS 로 결합자 확인 (`css-rules.md` 「SCSS 작성 규칙」)
- [ ] 새 공통 컴포넌트는 `components/` 의 **해당 부분 파일**에 — 종류가 새로우면 `_이름.scss` + 엔트리 `@use` + 목차 갱신, 반응형은 그 파일 끝 (`css-architecture.md`)

### JS (있을 때)

- [ ] 인라인 `<script>` 없음, `(function ($) { … })(jQuery)` + `"use strict"` + 요소 가드 (`javascript.md`)
- [ ] CSS 는 `common.css` `<link>` 하나, jQuery · GSAP 은 로컬 `common/js/lib/` 에서 각각 한 벌만 로드(CDN 없음, 기존 자산 버전 확인), 로드 순서 `jquery → gsap → 라이브러리 → common.js → 페이지 JS`. 스크롤 · 진입 모션 감지는 GSAP ScrollTrigger, 진입 모션의 움직임은 CSS (`javascript.md` 「공통 조각」 · 「모션」)
- [ ] `var` 없음, 스타일 직접 조작 없음(클래스·CSS 변수만 — `.show()` · `.css()` 로 모양 안 바꿈), `hidden` 은 `.prop`, 상태 전환 시 ARIA 동기화 (`javascript.md` 「DOM 과 상태」)
- [ ] 첫 화면 상태는 CSS — 들어올 때 움직이는 것의 시작값을 JS(`gsap.from` · 시작값 `gsap.set` · 숨김 클래스 부여)가 걸지 않는다. 캐시 비우기 새로고침으로 「보임 → 숨김 → 등장」 같은 튐이 없는지 (`javascript.md` 「모션」 첫 항목)
- [ ] 얼럿 · 검증 · 조회 요청 코드 없음 — 개발 영역 (§12)
- [ ] `node --check` 통과, 콘솔 오류 0건 (`javascript.md` 「완료 전」)
