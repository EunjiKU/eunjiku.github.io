# 브라우저 지원 범위 · 크로스브라우저 QA — publishing 스킬의 참고 문서

> **언제 여는가** — 프로젝트 시작 때 지원 범위를 정할 때, 페이지를 완료하고 브라우저·기기 확인을 할 때, ES2020 이후 문법이나 최신 CSS(`:has()` · 컨테이너 쿼리 등)를 쓰고 싶을 때 연다. 프로젝트의 실제 범위는 `PROJECT.md` 「브라우저 지원 범위」가 우선한다.

## 1. 기본 지원 매트릭스

고객사가 따로 정하지 않으면 아래를 쓴다. 정해지면 `PROJECT.md` 에 **기본값과 다른 줄만** 적는다.

| 구분 | 브라우저 | 범위 |
| --- | --- | --- |
| PC | Chrome · Edge | 최신 2개 버전 |
| PC | Safari (macOS) | 최신 2개 메이저 |
| PC | Firefox | 최신 2개 버전 — 레이아웃 깨짐만 확인 |
| 모바일 | iOS Safari | 최신 2개 메이저 (iOS 의 다른 브라우저도 엔진이 같다) |
| 모바일 | Android Chrome · Samsung Internet | 최신 |
| — | IE 11 | **지원 안 함** — 요구되면 프로젝트 시작 전에 범위·비용을 다시 협의한다 |

이 범위면 `:has()` · `gap`(flex) · `inset` · `clip-path` · CSS 변수 · `aspect-ratio` 를 쓸 수 있다. JS 는 ES2015 까지가 기본이다 (`javascript.md` 「문법」).

## 2. 범위 밖 기능을 쓰고 싶을 때

1. [caniuse.com](https://caniuse.com) 에서 매트릭스의 가장 낮은 버전이 지원하는지 본다.
2. 지원하지 않으면 쓰지 않거나, 없어도 화면이 성립하는 **점진적 향상**으로만 쓴다 (`@supports` 로 감싼다).
3. 범위를 넓혀야 하면 `PROJECT.md` 를 고치고 결정 기록에 남긴다.

## 3. 크로스브라우저 QA 절차

페이지를 완료하면 `a11y-check` 다음에 아래를 한다. 브라우저 도구로 확인할 수 없는 항목은 **"육안 확인 필요"로 보고**한다 — 확인한 척하지 않는다.

| 순서 | 확인 | 방법 |
| --- | --- | --- |
| 1 | 세 폭(1920 · 1024 · 600)과 360 에서 가로 오버플로 없음 | `a11y-check` 자동 점검(가로 오버플로) |
| 2 | Chrome 에서 콘솔 오류 0건 | 개발자 도구 |
| 3 | Safari 계열 — `gap`·`mask`·`position: sticky`·`<input type="search">` 기본 모양·날짜 입력 | macOS Safari 또는 iOS 실기기 |
| 4 | iOS — 100vh 주소창 문제, 16px 미만 입력창 확대, 고정 헤더와 바운스 스크롤 | iOS 실기기 |
| 5 | Android — 폰트 렌더링(글자 잘림·행간), 터치 타깃 44px | Android 실기기 |
| 6 | 키보드만으로 전 기능 조작, `:focus-visible` 표시 | Tab · Shift+Tab · Enter · Space · Esc |
| 7 | 브라우저 확대 200% 에서 내용 손실 없음 | Ctrl + `+` |
| 8 | 인쇄가 필요한 화면이면 인쇄 미리보기 | — |

## 4. 자주 걸리는 브라우저 차이

- **Safari 의 `<button>`·`<input>`** — `appearance: none` 리셋이 빠지면 둥근 기본 모양이 남는다. `common/_reset.scss` 에 있는지 확인한다.
- **iOS 입력창 확대** — `font-size` 가 16px 미만인 입력창에 포커스하면 화면이 확대된다. rem 이 vw 기반이면 작은 화면에서 16px 아래로 내려가는지 실측한다.
- **`100vh`** — 모바일 주소창 높이가 포함된다. 전체 높이 레이어는 `100dvh` 를 `@supports` 로 덧입힌다.
- **mask 아이콘** — `-webkit-mask` 를 같이 쓴다. 포커스 가능한 요소에 직접 걸면 outline 이 잘린다 (`SKILL.md` §8).
- **스크롤바 폭** — Windows 는 스크롤바가 폭을 차지해 `100vw` 요소가 가로 오버플로를 만든다. `100vw` 대신 `100%`.
