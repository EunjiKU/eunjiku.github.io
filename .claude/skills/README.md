# 퍼블리싱 스킬

이 포트폴리오를 Claude Code 로 고칠 때 쓰는 스킬 세 개다. **스킬에는 규칙("어떻게")만 있고, 이 사이트의 값("무엇")은 루트 `CLAUDE.md` · `PROJECT.md` 에 있다.** 둘이 다르면 `CLAUDE.md` 가 우선한다.

| 스킬 | 언제 |
| --- | --- |
| `publishing` | HTML · CSS · JS 를 한 줄이라도 만들거나 고칠 때 — 코딩 컨벤션 본체 (`references/` 본문, `scripts/audit.js` 점검) |
| `a11y-check` | 작업을 마친 페이지의 접근성 실측 — 자동 점검 · 터치 타깃 · 대비 |
| `site-check` | 배포 전 전체 점검 — 코드 정리(안 쓰는 클래스 · 이미지 · 토큰 · 믹스인) · 반응형(아이패드 · 갤럭시 폴드 등 기기 폭) · 접근성 · SEO, 보고 형식 |

## 고칠 때의 규칙

- 스킬 본문에는 범용 규칙만 쓴다 — 이 사이트의 색값 · 날짜 · 결정은 `PROJECT.md` 「결정 기록」에.
- `SKILL.md` 가 길어지면 `references/` 로 빼고 「언제 여는가」 표에 한 줄 추가한다.
- 같은 규칙을 두 스킬에 두 번 쓰지 않는다 — 규칙은 `publishing` 에 한 번, `a11y-check` · `site-check` 는 링크한다.
- `publishing` · `a11y-check` 는 여러 프로젝트가 같이 쓰는 범용 본문이라 이 사이트 값으로 고치지 않는다 — 이 사이트만의 값은 `CLAUDE.md` 「프로젝트 설정」, 이 사이트만의 점검 절차는 `site-check`.
